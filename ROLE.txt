ARCHITECTURE (important)
- Algorithm engine written in C++17, compiled to WebAssembly with Emscripten
- Each algorithm takes input and returns a TRACE: an ordered list of steps (JSON). Each step has: the data state, highlighted elements (compare/swap/visit/found), the current code line number, and a one-line plain-English explanation
- Single exported C API: run_algorithm(const char* algoId, const char* inputJson) -> const char* traceJson
- Frontend only plays the trace. It contains no algorithm logic, so adding a new algorithm means adding a C++ function and a registry entry
- Commit the compiled .wasm/.js files into the repo so the host never needs Emscripten
- Frontend: Vite + React + TypeScript + Tailwind CSS + Framer Motion; SVG/Canvas for rendering
- No backend, no database, free hosting only
